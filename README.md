# 在线问卷系统第二阶段

本项目在[第一阶段代码](https://github.com/ctasr/online-survey-system-phase1/tree/8745aff8a830d74db0b01f0f6838742293afc98b)上继续修改。第二阶段在原仓库的 `phase2` 分支开发和提交，`main` 保留第一阶段原提交，不修改其文件或提交时间。请先切换到 `phase2` 分支，再按下文运行。第二阶段增加独立题目库、题目版本、共享、题库管理和跨问卷统计。已发布问卷中的题目与跳转规则固定，修改题目时创建新版本供后续问卷使用，已有问卷和答卷保持原样。完整变更及兼容性说明见 [第二阶段设计与变更](docs/第二阶段_设计与变更.md)。

`MONGO_DB_NAME` 默认仍为 `survey_phase1`，因此使用相同数据库配置时可读取第一阶段数据；题目库是新增集合，旧问卷不需要迁移才能继续使用。

JSON 接口的请求格式、路径、状态码和独立 API 测试见 [API.md](API.md)。第二阶段测试步骤与实际结果见 [第二阶段测试用例与结果](docs/第二阶段_测试用例与结果.md)。

## 环境

- Python 3.12 或更新版本
- MongoDB（本地或其他可连接的实例）

## 启动

使用Git下载第二阶段：`git clone --branch phase2 --single-branch https://github.com/ctasr/online-survey-system-phase1.git`。下载ZIP时也应确认当前分支为phase2；默认main是第一阶段。

在本文件所在目录打开 PowerShell，运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (!(Test-Path .env)) { Copy-Item .env.example .env }
```

先启动 MongoDB 服务，并在 `.env` 中填写连接地址。随后运行：

```powershell
.\.venv\Scripts\python.exe run.py
```

打开 http://127.0.0.1:5000/ 。程序启动时会向 MongoDB 发送 `ping`；若连接失败，会立即显示错误，便于检查服务和地址。

账号页面：

- `/register`：注册。系统去除用户名首尾空格，拒绝空白用户名和已存在的同名账号。
- `/login`：登录。密码长度必须为 6～12 位，注册时需要重复输入确认；输入框可以切换显示或隐藏。
- `/dashboard`：只有登录后才能访问的个人页面。
- 退出登录：登录后使用页面上的“退出登录”按钮。

问卷页面：

- `/surveys`：登录用户只看到自己创建的问卷。可按标题搜索、按状态筛选；列表按页显示。
- `/surveys/new`：创建问卷，填写标题、说明、是否允许匿名填写、同一账号可提交次数和可选的截止时间。截止时间按北京时间输入，数据库中保存 UTC 时间。
- `/surveys/<问卷ID>`：本人查看详情、修改截止时间、发布或关闭问卷。问卷至少有一道题目才能发布。详情页会提示可能重叠、失效或无法命中的跳转规则，但提醒不会阻止发布。
- `/surveys/<问卷ID>/edit`：本人可修正问卷标题、说明、是否允许匿名和重复填写规则，包括已发布或已关闭的问卷。实际修改信息或填写设置后，已打开的填写页会在提交时提示更新并保留未改动题目的输入；原样保存不产生新版本。已提交答卷保持原样；从允许多次切换为仅一次时，以这次切换为新限制的起点，不追溯此前不限次时的答卷。
- `/surveys/<问卷ID>/preview`：创建者在发布前或发布后按填写者视角预览题目、校验和跳转。预览使用相同的题目规则，但不会写入答卷，也不会改变统计；只有创建者可以访问。
- `/surveys/<问卷ID>/questions/new`：本人在草稿问卷中按顺序添加题目。支持单选、多选、文本填空和数字填空；后二者是填空题的两种形式。
- 问卷详情中的“编辑题目”“删除题目”：草稿问卷可修改、删除题目。发布后题目固定；需要调整时可在题目库中创建新版本，供其他草稿问卷选用。旧答卷不会被新版本重新解释。数字上下限仅换成等价写法，例如0与0.0，不算修改题义，不改变版本或来源。
- 问卷详情中的“为本题添加跳转规则”：草稿问卷可配置单选、多选和数字题跳转；发布后规则固定。允许重叠条件，优先级从上到下，第一条命中的有效规则生效。
- `/question-library`：查看自己的题目、他人共享的题目和个人题库；可按题目内容搜索、分页浏览、创建题目或题库。从某个题库新建题目可直接加入该题库。
- `/question-library/<题目版本ID>`：查看当前版本、历史版本、共享状态、使用它的问卷及跨问卷统计；数字题按设置突出分布或均值等汇总。本人问卷的逐条填写内容每页20条，按提交时间及ID排序，翻页保留筛选和返回路径。可从旧版创建新版或恢复旧版内容为最新版本。
- `/surveys/<问卷ID>/question-library`：给草稿问卷连续选用指定版本，也可从此处新建并直接加入。问卷保存该版本的独立快照，不随题库后续更新。
- `/survey/<公开标识>`：问卷链接。草稿不可访问；已发布且未过期的问卷要求填写者先登录并可提交；关闭或过期后无法提交。
- `/surveys/<问卷ID>/statistics`：本人查看整卷统计，包括答卷总数、匿名/账号提交数、提交时间；各题有效回答数、选答未填数、未包含此题的答卷数；单选和多选各项数量与比例、文本原文和重复次数。数字题默认突出答案分布与回答份数，平均值等放在收起的“数值概览”中；测量类数字题可在题目设置中选择直接展示平均值、中位数和范围。选项比例以对应题目版本的有效回答数为分母。
- `/surveys/<问卷ID>/statistics/<题目ID>`：本人单独查看某道题的同一统计结果；整卷统计页提供每题入口。

“允许匿名填写”启用时仍需先登录，填写者可选择本次匿名或使用账号填写；匿名答卷不保存明文账号 ID，统计页也不展示身份。未启用时按账号填写。重复填写规则由创建者选择，默认允许多次且每次都另存一份答卷；选择“只允许一次”后，同一账号再次进入会看到提示。对于限制一次的问卷，系统只保存按问卷和账号生成的内部防重标记，并用 MongoDB 唯一索引防止同时提交两份。请保持 `SECRET_KEY` 稳定，否则旧防重标记无法用于识别同一账号。

题目规则由服务器在提交时验证：单选必须从设定选项中选；多选可设最少、最多或固定选择项数；文本可设最少和最多字数；数字可设最小值、最大值及整数要求。非必答题可以留空，填写后仍须满足相应限制。数字输入最多2050字符，整数与有效小数部分各最多1000位，配置范围、跳转阈值和答案使用同一检查。历史异常数字保留原文并单独提示，不拖垮统计页面。未通过验证的答卷不会写入 MongoDB。

创建和编辑问卷、题目时，离开有未保存内容的表单前，浏览器会提醒。多选题的数量设置分为“最少与最多”和“固定选几项”两种输入方式，避免同时填写冲突规则；服务器仍会独立验证提交内容。

跳转规则保存在问卷题目中，不写死在程序里。单选按选项匹配；多选可选择“包含任意一个”“包含全部”“完全相同”三种匹配方式；数字可比较小于、小于或等于、等于、大于或等于、大于。只允许跳到后面的题目，以免出现循环；多条规则按列表顺序检查，第一条命中即生效，没有命中时进入下一题。填写页根据已答内容更新可见题目和题目总览；提交时服务器重新计算经过的题目，只验证和保存实际经过的答案，被跳过的题目无需作答。未提交的输入会暂存，重新打开同一问卷可以继续填写。

统计页面每次打开时直接读取已保存的答卷重新生成结果。被跳过或留空的题目不计入该题有效回答数；平均值和中位数只使用有效数字回答，最多显示两位小数。统计按答卷而非去重后的账号计数，因此允许同一账号多次提交时，每次提交均计入统计。“未包含此题”表示条件跳转未经过该题，或第一阶段历史答卷提交时尚无该题，不等同于填写者主动留空。第二阶段不允许在已发布问卷中新增题目。

题目库保存可复用的独立题目版本；问卷仍嵌入题目快照以保持第一阶段结构和答题性能。已发布问卷题目和跳转规则不可再更改；第一阶段留下的 `question_history` 及旧答卷定义仍可读取，原有统计逻辑继续解释旧答卷。问卷标题、说明和填写设置仍可依第一阶段规则调整；填写页面带签名快照，服务器在提交时复核问卷状态。

密码仅以散列值保存在 MongoDB。登录状态保存在当前浏览器的签名 Cookie 中，关闭浏览器后仍可继续使用；默认有效期为 30 天，退出登录会立即使当前浏览器的登录状态失效。不同浏览器需要分别登录。

## 配置

在 `.env` 中设置：

- `MONGO_URI`：MongoDB 连接地址，示例为本地 `mongodb://127.0.0.1:27017/`。
- `MONGO_DB_NAME`：本项目使用的数据库名称，默认 `survey_phase1`。
- `SURVEY_HOST`：服务监听地址，默认 `0.0.0.0`，可通过当前局域网地址访问。
- `SURVEY_PORT`：服务端口，默认 `5000`。
- `PUBLIC_BASE_URL`：设置本项目可供其他人访问的公网地址，可以是域名或公网 IP。未设置时，页面不生成可复制的公开链接，API 的 `public_url` 为 `null`；本机 `127.0.0.1` 地址不能作为对外分享链接。
- `SESSION_DAYS`：同一浏览器的登录有效天数，默认 30。
- `SECRET_KEY`：可选。若未设置，程序会在 `instance/secret_key` 中自动生成并保存，用于维持登录状态；请保管该文件。

`.env` 和 `instance/secret_key` 不应提交，其中可能包含数据库凭据或会话密钥。程序沿用第一阶段索引，并为新增的 `question_library` 和 `question_banks` 建立版本、所有者及题库名称索引。
