## 复核时发现并处理的差异

1. `docs/MongoDB-schema.md` 曾把选答留空也写成“不保存”。实际代码保存到达但未答的题为 `value: null`，以区分跳过；已修正文档。
2. schema 示例中的单选跳转曾遗漏 `kind: "single_choice"`，已按真实存储结构补上。
3. Windows 本地运行不需要 Linux 的 Gunicorn；`requirements.txt` 已对 Gunicorn 增加平台条件，Linux 部署仍会安装。
4. 本轮完整测试重新运行：`Ran 41 tests in 108.580s`，`OK`；公网 `/` 与 `/api/v1/csrf` 返回 200，未登录 `/dashboard` 返回 302。公网 HTTPS 证书通过系统默认验证。
