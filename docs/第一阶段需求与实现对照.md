# 第一阶段需求与实现对照

本表依据《大作业一》的初始需求及开发中用户明确提出的交互修正编制。它将“作业最低要求”与“体验改进”分开，避免用一句“功能已完成”掩盖实际代码位置。第二阶段尚未发布的新需求不列为已实现。

## A. 原文件初始需求

| 编号 | 原文件要求 | 实现位置 | 核对方式 |
| --- | --- | --- | --- |
| A01 | 注册账号，保存用户名、密码与注册时间 | `app/auth.py`、`app/api.py` 写入 `users`，密码以散列保存；`app/db.py` 建用户名唯一索引 | `tests/test_auth.py`、`tests/test_json_api_http.py` |
| A02 | 登录后使用个人账号，用户只看自己的问卷 | `app/auth.py` 登录会话；`app/surveys.py` 的 `owned_survey`；`app/api.py` 的 `owned` | `tests/test_surveys.py`、`tests/test_json_api.py` |
| A03 | 创建问卷：标题、说明、是否允许匿名 | `app/surveys.py` 的 `create_survey`，`surveys/new.html`；`surveys` 集合存相应字段 | `tests/test_surveys.py` |
| A04 | 查看本人问卷列表，编辑问卷和截止时间，关闭问卷 | `app/surveys.py` 的 `my_surveys`、`edit_survey`、`set_deadline`、`close`；对应模板 | `tests/test_surveys.py` |
| A05 | 每份问卷有可发送的 `/survey/<标识>` 链接；填写者须登录 | `app/sharing.py`、`app/surveys.py` 的 `public_survey`、`app/auth.py`；公网地址由 `PUBLIC_BASE_URL` 配置 | `tests/test_sharing.py`、`tests/test_full_journey.py` |
| A06 | 单选题：自定义选项、可设必答 | `app/questions.py` 的 `build_question` 与 `validate_answer` | `tests/test_questions.py` |
| A07 | 多选题：最少、最多或固定项数 | `app/questions.py` 校验选项集合和数量；`question_new.html` 配置界面 | `tests/test_questions.py`、`tests/test_json_api.py` |
| A08 | 文本填空：最少和最多字数 | `app/questions.py` 文本分支 | `tests/test_questions.py` |
| A09 | 数字填空：范围和整数限制 | `app/questions.py` 数字分支，有限数字检查 | `tests/test_questions.py` |
| A10 | 单选、多选和数字条件跳转，创建者可配置 | `app/jumps.py`、`app/surveys.py` 的跳转管理与 `jump_new.html` | `tests/test_jumps.py`、`tests/test_jump_review.py` |
| A11 | 按题目顺序填写；命中规则自动跳转；错误回答提示 | `app/jumps.py` 的 `next_question_index`，`app/surveys.py` 的 `assess_response`，`app/static/app.js` | `tests/test_jumps.py`、`tests/test_answer_overview.py` |
| A12 | 完成后提交，每份答卷保存；多人、匿名、重复填写可配置 | `app/surveys.py`、`app/api.py` 写 `responses`，`app/db.py` 的防重唯一索引 | `tests/test_submissions.py`、`tests/test_full_journey.py` |
| A13 | 单选统计每项人数和总回答人数 | `app/statistics.py` 计算 `option_counts`、`answered_count`；统计模板显示 | `tests/test_statistics.py` |
| A14 | 多选统计每项被选次数 | `app/statistics.py` 多选分支 | `tests/test_statistics.py` |
| A15 | 填空可看原文，数字可看平均值 | `app/statistics.py` 的 `values`、`average`；单题模板提供原文和数值概览 | `tests/test_statistics.py` |
| A16 | 查看整卷和单题统计，结果随已保存答卷自动更新 | `app/surveys.py` 的 `statistics`、`question_statistics`；`app/api.py` 的统计端点 | `tests/test_statistics.py`、`tests/test_json_api_http.py` |
| A17 | MongoDB 设计不能把所有数据塞进一个集合，逻辑不能写死 | `app/db.py` 建 `users`、`surveys`、`responses`、`response_drafts` 索引；题目和规则存入问卷文档 | `docs/MongoDB-schema.md`、`docs/系统与数据库设计.md` |
| A18 | 代码可运行，提交文档、API、测试步骤/输入/输出/结果、报告和 AI 过程 | `run.py`、`README.md`、`API.md`、`docs/`、`tests/` | `docs/第一阶段提交清单.md`；41 项自动测试通过 |

## B. 用户在实际使用中提出的修正

| 编号 | 体验与业务判断 | 最终对应位置 |
| --- | --- | --- |
| B01 | 必答是默认，突出选答；题号数字，A/B/C/D 仅用于选项 | `app/numbering.py`、`question_new.html`、`public.html` |
| B02 | 填写时可总览已答/未答；未答必答不能提交；提交前确认不可修改 | `public.html`、`app/static/app.js`、`app/questions.py` |
| B03 | 长问卷不靠从上到下连续滚动，管理与统计也能搜索、分页和切换视图 | `app/static/app.js`、`detail.html`、`statistics.html`、`response_detail.html` |
| B04 | 问卷管理要看真正的发布时间，区别于创建时间 | `app/surveys.py`、`list.html` |
| B05 | 创建者可看具名答卷和每题各选项的作答账号；匿名身份不公开 | `app/surveys.py`、`statistics.html`、`_question_statistics.html` |
| B06 | 不显示无必要的填写路径分布；数字题按答案型/测量型调整重点 | `app/statistics.py`、`app/questions.py`、`_question_statistics.html` |
| B07 | 关闭、删除、提交等关键动作使用清楚的站内确认，而非生硬系统弹窗 | `app/templates/base.html`、`app/static/app.js` |
| B08 | 本机地址不冒充公网链接；不同网络可用同一公网部署 | `app/sharing.py`、`.env.example`、`deploy/`、`tests/test_sharing.py` |
| B09 | 数学演示题答案唯一；足球按了解程度分支，不按喜爱球员分支 | `tools/replace_demo_surveys.py`、`output/当前演示问卷/` |

以上“对应位置”指最终代码，不表示 AI 初版就正确。逐项提示、AI 结果及用户纠正见 [AI 使用记录](AI使用记录.md)。
