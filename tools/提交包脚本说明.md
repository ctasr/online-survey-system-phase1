# 提交包中的辅助脚本

`app/`、`run.py` 和 `requirements.txt` 是运行问卷系统所需代码；`tests/` 是自动测试。这里的脚本仅用于开发时生成演示数据或截图，**启动系统和运行自动测试都不需要执行它们**。

| 脚本 | 用途 | 使用边界 |
| --- | --- | --- |
| `check_large_ux.py` | 在临时数据库构造多题问卷并截取页面 | 需要另装 Playwright 及浏览器；仅作界面检查。 |
| `capture_real_journey.py` | 记录注册到统计的页面流程 | 需要 Playwright；截图已放入 `output/`。 |
| `replace_demo_surveys.py`、`seed_experience_surveys.py` | 开发阶段更换指定演示问卷 | 依赖当时的问卷 ID，可能删除旧演示数据；仅作 AI 过程代码证据，**不要在新安装或正式数据上运行**。 |
| `seed_all_accounts_answers.py` | 为演示账号提交合成答卷 | 假定恰好存在对应演示账号与问卷；会写入数据，不属于常规启动步骤。 |
| `capture_current_statistics.py` | 截取当前演示统计页 | 使用开发机的 Edge 路径；图片已放入 `output/`。 |

课程提交和验收应优先使用 `README.md` 的启动步骤、`tests/` 的自动测试和 `docs/测试用例与结果.md`；辅助脚本的固定账号或旧 ID 不属于通用业务功能。
